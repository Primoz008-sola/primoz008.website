# primoz008.website

Primoževa osebna portfolio spletna stran.

## Opis

Moderna, odzivna portfolio spletna stran zgrajena z HTML, CSS in JavaScript. Vsebuje naslednje razdelke:

- **Domov** – pozdravni zaslon s tipkanim besedilom in socialnimi povezavami
- **O meni** – kratka predstavitev, izobrazba, izkušnje in strasti
- **Veščine** – frontend, backend ter orodja z animiranimi vrsticami napredka
- **Projekti** – galerija projektov z opisi in tehnologijami
- **Kontakt** – kontaktne informacije in obrazec za sporočilo

## Značilnosti

- 🌙 Temna tema z modernim dizajnom
- 📱 Odziven na vse zaslone (mobile-first)
- ⚡ Gladke animacije in prehodi
- ♿ Dostopen (ARIA oznake, semantični HTML)
- 🚀 Čisti HTML/CSS/JS brez zunanjih odvisnosti za gradnjo

## Zagon

Odprite `index.html` v spletnem brskalniku ali strežite datoteke z lokalnim strežnikom, npr.:

```bash
npx serve .
```
